# Расходы голосом

Приложение для учёта трат: говоришь фразу — запись появляется сама.
Работает как обычное приложение на телефоне (PWA), данные хранятся только у тебя.

## Как запустить на компьютере

Двойной клик: **`Запустить-расходы.bat`**.

Откроется браузер на `http://localhost:8090`. В окне чёрного цвета будет ещё адрес
для телефона — он нужен, если телефон в той же Wi-Fi сети.

## Как поставить на телефон

1. Запусти `Запустить-расходы.bat` — в окне появится строка вида
   `http://192.168.1.10:8090`.
2. На телефоне открой этот адрес в Chrome (телефон и компьютер в одной Wi-Fi).
3. Меню Chrome (три точки) → **«Добавить на главный экран»** / «Установить приложение».
4. Дальше запускай с иконки — как обычное приложение.

Если хочется открывать без компьютера — приложение можно выложить на GitHub Pages
(бесплатно), как Gramotey. Скажи — сделаю.

## Что говорить

- «кофе двести пятьдесят»
- «такси триста сорок»
- «продукты тысяча двести»
- «полторы тысячи на подарок маме»
- «зарплата сорок тысяч»
- «пять косарей за ремонт»

Числа можно словами: «двести пятьдесят», «полторы тысячи», «двадцать пять тысяч».

## Что можно спросить

- «сколько на кафе» — сумма по категории за месяц
- «сколько осталось» — сколько до конца лимита и сколько в день
- «сколько я потратил сегодня»
- «сколько за неделю»
- «на что уходит больше»
- «отмени последнее» — убрать последнюю запись

## Правила разбора

| Что слышит | Что делает |
|---|---|
| «потратил, купил, заплатил, отдал» | расход |
| «получил, зарплата, пришло, вернули, кэшбэк» | доход |
| «занял, одолжил, в долг» | категория «Долги» |
| непонятная категория | откроет окно и предложит выбрать |

## Данные

- Хранятся в браузере телефона (localStorage), никуда не отправляются.
- «Месяц» → «Скачать таблицу» — файл CSV, открывается в Excel.
- «Удалить все записи» — сотрёт всё без возможности вернуть.

## Технические детали

- Без сборки и без зависимостей: чистые HTML/CSS/JS-модули.
- Распознавание речи — встроенный движок Chrome/Edge (`webkitSpeechRecognition`),
  нужен интернет. Записи и все итоги работают офлайн.
- Разбор фраз: `js/parser.js`, тесты — `node tests/parser.test.mjs` (55 проверок).
- Service worker: `sw.js`, кэш `rashody-vN`. После правок файлов поднимай версию кэша.
- Иконки перерисовываются скриптом `icons/make-icons.ps1`.
